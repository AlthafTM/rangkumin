# Reading, provenance, and fact-checking

## Source inventory

Record filenames or titles, versions, page ranges, and their role: primary material, assignment instructions, template, prerequisite, or supplementary reference. Use the latest version selected by the user. Do not silently mix requirement numbering, variable definitions, or revisions across documents.

For long material, create a working coverage table before drafting:

| Unit/question | Source location | Must preserve | Status |
|---|---|---|---|
| Topic or original number | File, printed page/slide | Formula, table, example, memory point | Read / verified / ambiguous |

This is an internal aid unless the user wants it in the output. Distinguish printed page numbers from PDF viewer indices when they differ.

## Extraction

Use text extraction for search and coverage, then inspect the rendered page for layout-sensitive content. For scans, OCR is a draft transcription. Verify inequality signs, upper/lower bounds, exponents, decimal separators, code indentation, arrow directions, and final-state markings against the image.

Crop or zoom unclear regions when tools permit. If an essential symbol remains unreadable, ask for that region or state a conditional interpretation. Do not infer a digit merely because it produces an expected answer.

## Duplicate handling

Compare question text, code, constants, start/end values, comparison operators, indentation, choices, and expected output. Two photos of the same question are one item; different parameters require separate answers. A photo of the lower half of a question is a continuation, not another exercise. Preserve a mapping such as “Question 5: images 8–9.” Missing questions must not be invented to make numbering continuous.

## Quotes and references

- Put quotation marks only around wording checked verbatim. Preserve relevant punctuation and record its location.
- A paraphrase uses your wording with attribution; it is not a direct quote. Clearly distinguish source statements from your analysis.
- A translation must be labelled as a translation, not represented as the original wording.
- Use only the reading(s) allowed by the user. Do not invent an author, year, page, DOI, title, quotation, or publication detail.
- Follow the requested citation style and supplied academic-writing rules. If the user asks for “dkk.” or no links, honor that where compatible with the task; do not substitute it blindly into a mandated reference style.
- If reference details are supplied by the question, copy and normalize them carefully. Mark genuinely missing details instead of guessing.

## Discrepancies

When a source result conflicts with a verified derivation, distinguish “printed result” from “corrected result” and show the decisive step. A concise correction is more useful than a long warning. Do not silently alter answer choices or original question wording. If the task asks only to reproduce the source, preserve it and separately flag the error when material.

## External verification

Use official documentation, original papers, or other primary sources for additions that need verification. Do not replace course conventions with a different convention without saying so. Verification is not permission to expand the syllabus. Keep any external additions identifiable and relevant.
